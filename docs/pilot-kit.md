# Pilot kit

## Scope

One course, one or two practice quizzes, 30-100 students who agree to take part, at least five
from each device row below. Run on a site configured like production.

## Device matrix to cover

| Device | Browser | Expect | Tested by / date / result |
| --- | --- | --- | --- |
| Windows laptop | Chrome, Edge | Camera and whole-screen share; self-view | |
| Windows laptop | Firefox | As above (screen shape check instead of surface report) | |
| macOS | Chrome, Safari, Firefox | Camera and screen; macOS asks for screen permission once | |
| Android phone | Chrome | Camera only, no screen (lenient mode) | |
| iPhone / iPad | Safari | Camera only, no screen (platform limit) | |
| Moodle mobile app | - | Blocked with a link to open in a browser | |
| Low bandwidth | any, throttled to 3G | Pre-check passes; uploads catch up | |

## Student briefing (send a week before)

- Use a computer if you can. You will share your camera and your whole screen.
- You will see yourself in a small window during the quiz, with a red "Recording" dot.
- If your connection drops, keep going; Moodle saves your answers and the snapshots catch up.
- An invigilator may send you a message or pause your quiz; you will see why on screen.
- Flags are only for a person to look at. Nobody fails because of a flag alone.
- Questions or problems: <support contact>.

## Staff briefing

- Report: quiz > More > Proctoring report. Live wall tab during the sitting.
- Every action needs a reason; students see actions, not your name.
- The score sorts what to look at first; it is not a probability of cheating.
- Decisions: "Concern" or "Refer" need written reasons; record appeals in the same place.

## Feedback to collect

Students: could you start without help (yes/no), anything confusing, device and browser, did the
self-view help. Staff: false flags seen (type, why), missing information, time spent per review.

## Exit criteria

All device rows tested, no blocking defect open, reviewer sign-off on flag usefulness and fairness,
students' top three problems fixed or explained.
